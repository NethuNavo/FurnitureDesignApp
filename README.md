# 🪑 FurniVision  

FurniVision is a modern **Next.js (App Router)** interior design web application that allows users to design and visualize rooms in both **2D and 3D**.

🌐 Live Demo: https://furniture-design-app-bzt8.vercel.app/login

---

## ✨ Features

- 🏠 2D Room Planning (drag & drop furniture)
- 🎮 3D Room Visualization using Three.js
- 💾 Save and manage design flows
- 🔐 Mock authentication system
- ⚡ API-based architecture (in-memory backend)

---

## 🛠️ Tech Stack

- Next.js 16 (App Router)
- React + TypeScript
- Tailwind CSS
- Three.js (3D rendering)
